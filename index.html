              📖 ডেটা সিঙ্ক সেটআপ গাইড

              নিজের Firebase প্রজেক্ট বানিয়ে সিঙ্ক চালু করার সম্পূর্ণ প্রক্রিয়া (একবারই করতে হয়, বিনামূল্যের Spark প্ল্যানই যথেষ্ট)।

              ক) Firebase প্রজেক্ট তৈরি

              1. ব্রাউজারে console.firebase.google.com খুলুন এবং Google অ্যাকাউন্ট দিয়ে লগইন করুন।
              2. Create a project (বা Add project) চাপুন → প্রজেক্টের একটা নাম দিন (যেমন my-discipline) → Continue। Google Analytics বন্ধ রাখতে পারেন → Create project।
              3. প্রজেক্ট তৈরি হলে Project Overview পেজে </> (Web) আইকনে চাপুন → অ্যাপের একটা nickname দিন → Register app।
              4. সেখানে firebaseConfig = { apiKey: …, authDomain: …, projectId: …, storageBucket: …, messagingSenderId: …, appId: … } দেখাবে। এই পুরো অংশটা কপি করে রাখুন।

              খ) লগইন পদ্ধতি চালু

              1. বাম মেনুতে Build → Authentication → Get started।
              2. Sign-in method ট্যাবে Email/Password বেছে Enable করুন → Save।

              গ) ডেটাবেজ চালু

              1. Build → Firestore Database → Create database।
              2. লোকেশন বেছে নিন (কাছের কোনোটা, যেমন asia-south1) → Production mode → Create/Enable।
              3. Rules ট্যাবে যান, আগের লেখা মুছে নিচের রুলস পেস্ট করে Publish চাপুন (এতে প্রত্যেকে শুধু নিজের ডেটা পড়তে/লিখতে পারবে): 
                rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}

              ঘ) অ্যাপে বসানো

              1. এই অ্যাপের সেটিংস → ☁️ ডেটা সিঙ্ক অংশে যান।
              2. ১) Firebase কনফিগ বক্সে কপি করা firebaseConfig অংশটা পেস্ট করে 💾 কনফিগ সেভ চাপুন। "কনফিগ সেভ আছে" লেখা দেখাবে।
              3. ২) অ্যাকাউন্ট অংশে ইমেইল ও পাসওয়ার্ড (কমপক্ষে ৬ অক্ষর) দিয়ে ＋ নতুন অ্যাকাউন্ট বানান চাপুন। এই ডিভাইসের বর্তমান ডেটা নতুন অ্যাকাউন্টে আপলোড হয়ে যাবে।
              4. নিচে ডান পাশে "সিঙ্ক হয়েছে" লেখা এলে কাজ শেষ।

              ঙ) আরেকটা ডিভাইসে একই অ্যাকাউন্ট

              1. ওই ডিভাইসে অ্যাপ খুলে একই firebaseConfig পেস্ট করে সেভ করুন।
              2. একই ইমেইল-পাসওয়ার্ড দিয়ে 🔑 লগইন চাপুন (নতুন অ্যাকাউন্ট নয়)।
              3. ডিভাইসে আগে থেকে আলাদা ডেটা থাকলে অ্যাপ জিজ্ঞেস করবে ক্লাউডের না এই ডিভাইসের ডেটা রাখবেন। সাধারণত OK = ক্লাউডের ডেটা বেছে নিন।

              চ) একাধিক অ্যাকাউন্ট ও দ্রুত সুইচ

              1. লগইনের সময় "এই ডিভাইসে পাসওয়ার্ড সেভ রাখুন" টিক দিয়ে রাখুন।
              2. আরেকটা অ্যাকাউন্ট যোগ করতে ইমেইল-পাসওয়ার্ড লিখে আবার লগইন বা নতুন অ্যাকাউন্ট চাপুন।
              3. অ্যাকাউন্টের তালিকায় যেটার পাশে সুইচ চাপলেই এক ট্যাপে ওই অ্যাকাউন্টে চলে যাবেন। সুইচের সময় এই ডিভাইসে ওই অ্যাকাউন্টের ডেটা দেখাবে।

              কিছু জরুরি কথা

              • ডেটা ডিভাইসেই সেভ থাকে; ইন্টারনেট না থাকলে অ্যাপ আগের মতোই চলে এবং ইন্টারনেট এলে পরিবর্তনগুলো নিজে থেকে সিঙ্ক হয়।
              • সিঙ্ক সার্ভিসের লাইব্রেরি প্রথমবার ইন্টারনেটে লোড হয়; এরপর ব্রাউজার ক্যাশ করে রাখে।
              • লগইনে "domain not authorized" ধরনের সমস্যা এলে Firebase-এ Authentication → Settings → Authorized domains-এ আপনার অ্যাপ যে ডোমেইনে খুলছেন (যেমন নাম.github.io) সেটা যোগ করুন।
              • সেভ করা পাসওয়ার্ড এনক্রিপ্টেড নয়, তাই শুধু নিজের ডিভাইসে সেভ রাখুন।
              • আপনার কনফিগ ও ডেটা শুধু আপনার নিজের Firebase প্রজেক্টে থাকে।
